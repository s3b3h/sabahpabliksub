# Sabah Public Sub

اشتراك v2rayNG يتحدث تلقائياً من قنوات تيليجرام.

## المنابع
| القناة | العدد | الأرقام | إذا ما عُرف العلم |
|---|---|---|---|
| @TheFreeConfigs | آخر 50 غير مكرر | Sabah 1 → 50 | 🌐 |
| @tootffarangi2 | آخر 150 غير مكرر | Sabah 51 → 200 | 🍓 |

المجموع: 200 كونفيج.

## المميزات
- تخطي سيرفرات الشادوساكس (`ss://` و `ssr://`) — ما تدخل في الاشتراك ولا في العدد (الإعداد `SKIP_PROTOCOLS`).
- حذف التكرار الذكي (نفس السيرفر حتى لو اختلف ترتيب الباراميترات/الاسم/fp/sid/spx) وعبر كل المنابع.
- علم دولة السيرفر الحقيقية عن طريق GeoIP (ip-api.com)، وإذا كان السيرفر خلف CDN يستخدم العلم الأصلي أو الإيموجي البديل.
- إذا فشل منبع، تبقى كونفيجاته القديمة.
- يتحدث كل 15 دقيقة عبر GitHub Actions (`.github/workflows/update.yml`) + تشغيل يدوي + تشغيل تلقائي بعد تعديل السكربت.
